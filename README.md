# Sales & Lead KPI Analytics

End-to-end analysis of lead and sales performance for a multi-site call-center operation:
**data cleaning, KPI design, funnel analysis, source ROI, speed-to-lead, agent performance**
and clear, actionable recommendations. Every number is reproducible from code.

> Portfolio project by Sameer Ahmed Shahid. The dataset is **synthetic** (generated by
> `src/generate_data.py`) and models the kind of operational data I analyse professionally;
> no real customer data is included.

![Speed to lead](reports/figures/03_speed_to_lead.png)

## Key findings

- **Speed to lead is the biggest lever.** Leads contacted within 5 minutes convert at **23.3%**
  vs **8.0%** after 2+ hours (2.9x).
- **Source quality varies widely.** Referral leads convert at **31.1%**; affiliate leads at **6.6%**,
  with a cost per sale over 4x higher than Google Ads.
- **Agent tenure matters.** Conversion rises from 13.1% (0-6 months) to 17.0% (24+ months).
- **Weekends underperform.** 13.5% conversion on weekends vs 16.9% on weekdays.

Full write-up with KPI table, source performance and charts: **[reports/summary.md](reports/summary.md)**

## What this project demonstrates

| Skill | Where |
|---|---|
| Data cleaning (duplicates, inconsistent labels, invalid values) | `src/analysis.py` · `load_and_clean()` |
| KPI design (contact, qualification, conversion, ROAS, cost per sale) | `src/analysis.py` · `kpis()` |
| Python / Pandas analysis and Matplotlib visualisation | `src/analysis.py` |
| SQL: aggregation, CASE buckets, JOINs, CTEs, window functions (RANK, LAG) | `sql/kpi_queries.sql` |
| Cross-checking results between Pandas and SQL | `src/run_sql.py` |
| Turning analysis into business recommendations | `reports/summary.md` |

## Project structure

```
data/                 synthetic raw export (leads_raw.csv) + agents.csv
src/generate_data.py  reproducible synthetic data generator (seeded)
src/analysis.py       cleaning, KPIs, charts, written summary
src/run_sql.py        loads clean data into SQLite and runs the SQL queries
sql/kpi_queries.sql   KPI queries
reports/summary.md    findings, recommendations and charts
reports/figures/      generated charts
```

## Run it

```bash
pip install -r requirements.txt
python src/generate_data.py   # optional: regenerate the dataset
python src/analysis.py        # rebuild charts and reports/summary.md
cd src && python run_sql.py   # run the SQL versions of the KPIs
```

The clean dataset can also be loaded straight into Power BI, Tableau or Looker Studio
for interactive dashboards.
